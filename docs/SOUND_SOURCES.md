# SVOperation sound asset sources

The SV-01 prototype uses CC0 1.0 sound effects from SFXMint. CI downloads WAV masters and converts them to OGG Vorbis for Minecraft.

| In-game event | Source asset | Direct source |
|---|---|---|
| Fire variation 1 | Distant Rifle Gunshot 08 | https://sfxmint.com/dl/impact-gunshot-08.wav |
| Fire variation 2 | Sharp Gunshot 16 | https://sfxmint.com/dl/impact-gunshot-16.wav |
| Magazine handling | Quick Gun Reload Click 14 | https://sfxmint.com/dl/mechanical-reload-14.wav |
| Bolt cycle | Rifle Bolt Gun Cocking 03 | https://sfxmint.com/dl/gun-cocking-03.wav |

SFXMint declares these effects CC0 1.0, including commercial use, modification and redistribution without attribution. Source pages: https://sfxmint.com/sounds/impact-gunshot-08, https://sfxmint.com/sounds/gun-cocking-03, https://sfxmint.com/sounds/mechanical-reload.
