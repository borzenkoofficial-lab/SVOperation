# SVOperation — архитектура

## Текущий статус

Это стартовый каркас Forge-мода. Пока реализована только точка входа и инфраструктура сборки.

## Модули по зонам ответственности

Будущие подсистемы будут добавляться постепенно, только после проверки базового проекта:

- **Core** — общие реестры, конфигурация, версии и совместимость.
- **Arsenal** — игровые предметы, боеприпасы, баллистика и анимации.
- **Equipment** — экипировка, броня и визуальные слои.
- **Vehicles** — транспорт и его игровые компоненты.
- **World** — структуры, декорации и тематические локации.
- **AI** — поведение игровых NPC и команды.
- **Scenarios** — задания, игровые события и сценарные цепочки.
- **Networking** — синхронизация данных между клиентом и сервером.

## Архитектурные правила

1. Регистрация контента — через отдельные registry-классы.
2. Логика, влияющая на игровой мир, должна выполняться на серверной стороне.
3. Клиентский код (рендеринг, HUD, модели) изолируется от dedicated server.
4. Сетевые сообщения имеют явные типы, валидацию и ограничения частоты.
5. Конфигурации имеют безопасные значения по умолчанию.
6. Каждая подсистема получает минимальные тесты и проверку загрузки.
7. Сторонние библиотеки добавляются только при обоснованной необходимости.

## Порядок разработки

1. Подтвердить воспроизводимую сборку на Forge 1.21.1.
2. Проверить запуск клиента и dedicated server.
3. Добавить локализацию и систему конфигурации.
4. Реализовывать игровой контент небольшими вертикальными срезами.
5. Выпускать JAR только после зелёной CI-сборки.
